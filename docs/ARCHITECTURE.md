## 1. Analytics & Machine Learning Pipeline

### A. RFM Customer Segmentation
- **Recency ($R$)**: Days elapsed since customer's most recent transaction. Quantized into quintiles (1–5).
- **Frequency ($F$)**: Total number of lifetime completed orders. Quantized into quintiles (1–5).
- **Monetary ($M$)**: Cumulative revenue generated by customer. Quantized into quintiles (1–5).
- **Classification**:
  - **Champions**: $R \ge 4, F \ge 4, M \ge 4$
  - **Loyal Customers**: $R \ge 3, F \ge 3$
  - **Potential Loyalists**: $R \ge 3, F < 3, M \ge 3$
  - **New Customers**: $R \ge 4, F = 1$
  - **At Risk**: $R \le 2, F \ge 3$
  - **Cannot Lose Them**: $R = 1, F \ge 4, M \ge 4$
  - **Lost Customers**: $R \le 2, F \le 2, M \le 2$

### B. Cohort Retention Heatmap
- Tracks user acquisition cohorts ($C_m$) over monthly time horizons ($M_0, M_1, M_2, \dots, M_5+$).
- Calculates the retention percentage $\text{Retention}_{m, t} = \frac{\text{Active Customers}_{m, t}}{\text{Cohort Size}_m} \times 100\%$.

### C. Time Series Forecasting (Scikit-Learn)
- Multi-variate Ridge regression modeling:
  $$\hat{y}_t = \beta_0 + \beta_1 t + \sum_{k=1}^6 \gamma_k \text{DOW}_{k, t} + \delta \cdot \text{Weekend}_t$$
- **Confidence Intervals**: 95% statistical confidence bounds incorporating forecast horizon uncertainty:
  $$\text{CI}_{95\%} = \hat{y}_t \pm 1.96 \cdot \hat{\sigma}_{\epsilon} \cdot \left(1 + 0.4 \cdot \frac{t}{T}\right)$$

### D. Anomaly Detection
- Rolling 14-day window statistical standard score:
  $$Z_t = \frac{x_t - \mu_{14}}{\sigma_{14}}$$
- Flags:
  - $Z_t < -1.8$: Revenue drop alert (Critical/Warning)
  - $Z_t > 2.0$: Order surge opportunity
  - $\text{Return Rate}_t > 5.5\%$: Quality/sizing discrepancy alert

## 2. Frontend UI Architecture
- **Dual Connectivity**: Seamlessly switches between live FastAPI endpoints and high-performance client-side fallback computation.
- **State Management**: Centralized reactive filter store propagating changes across KPI cards, time-series charts, top products, cohort heatmaps, and AI recommendations without full page reloads.
- **Theme System**: CSS variable-driven Dark / Light mode with persistence and system media query sync.
- **Command Palette**: `Ctrl + K` global keyboard spotlight for instant SKU, customer, and page discovery.
