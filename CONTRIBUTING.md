# Contributing to E-Commerce Intelligence

Thanks for your interest in improving this project.

## Ways to contribute

- Improve analytics logic or data-quality checks
- Fix bugs
- Improve documentation
- Add tests
- Improve dashboard usability
- Suggest new business metrics or analytical features

## Development workflow

1. Fork or create a feature branch.
2. Make one focused change.
3. Test the change locally.
4. Update documentation when behavior changes.
5. Open a pull request with a clear description of the problem and solution.

## Pull requests

Please keep pull requests focused and explain:

- What changed?
- Why was the change needed?
- How was it tested?
- Are there any limitations or follow-up improvements?

## Analytics contributions

For new metrics or analytical methods, please document the business definition, assumptions, inputs, and expected interpretation so that results remain reproducible and understandable.

## Code quality

Prefer small, readable functions and clear naming. Avoid committing secrets, credentials, local environment files, or generated database artifacts that are not required by the project.
